# ВКЛЮЧЕ

Прототип автомобильного маркетплейса с каталогом, размещением объявлений, импортом Avito-совместимых XML-фидов и интерактивным автоаукционом.

## Возможности

- каталог автомобилей, поиск, фильтры и избранное;
- расширенный адаптивный фильтр: все параметры открываются выпадающими списками с галочками и поддерживают множественный выбор;
- размещение объявления с фотографиями и характеристиками;
- документы автомобиля, два способа связи и профиль продавца в карточке объявления;
- связанные справочники марок и моделей;
- импорт объявлений из XML-фида;
- аукционы со ставками, таймером и выбором победителя.
- регистрация, вход, восстановление пароля, роли и личный кабинет через Supabase Auth.
- автоматическое получение XML-фидов по расписанию, журнал запусков и защита от случайного снятия объявлений.

## Настройка авторизации

1. Создайте проект в Supabase.
2. В `Authentication → URL Configuration` добавьте адрес опубликованного сайта и локальный адрес разработки.
3. Скопируйте `Project URL` и публичный `anon key` в `supabase-config.js`.
4. Выполните `supabase-schema.sql` в SQL Editor, чтобы создать профили и политики доступа.

`service_role` key нельзя добавлять в файлы сайта или отправлять в GitHub. Пока настройки не указаны, сайт показывает экран подключения вместо небезопасной демо-авторизации.

## Автоматическая загрузка фидов

1. Повторно выполните актуальный `supabase-schema.sql` в SQL Editor.
2. После регистрации администратора замените `YOUR_ADMIN_EMAIL` в локальной копии `supabase-admin.sql` и выполните её, не публикуя личный адрес в GitHub.
3. Опубликуйте функцию: `npx supabase functions deploy import-feeds --project-ref whlszhqkmvfwynwgiqnq --no-verify-jwt`.
4. Добавьте функции секрет `CRON_SECRET` со случайным длинным значением.
5. Укажите то же значение вместо `CHANGE_ME` и выполните `supabase-cron.sql`.
6. На сайте откройте «Загрузить фид», добавьте URL в блоке «Автоматические фиды» и нажмите «Загрузить сейчас» для проверки.

По умолчанию источник проверяется каждый час. Если автомобиль отсутствует в двух последовательных успешных версиях фида, он скрывается из каталога. Ошибка скачивания не считается пропуском и не снимает объявления с публикации.

## Локальный запуск

Проект не требует сборки. Запустите любой статический HTTP-сервер в этой папке, например:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Совместная работа

Предложения и ошибки создавайте в GitHub Issues. Изменения разрабатывайте в отдельных ветках и отправляйте через Pull Request.

> Сейчас объявления, ставки и избранное сохраняются в `localStorage`, поэтому данные из разных браузеров не синхронизируются. Для совместных данных потребуется серверная часть.
