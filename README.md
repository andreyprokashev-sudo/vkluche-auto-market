# ВКЛЮЧЕ

Прототип автомобильного маркетплейса с каталогом, размещением объявлений, импортом Avito-совместимых XML-фидов и интерактивным автоаукционом.

## Возможности

- каталог автомобилей, поиск, фильтры и избранное;
- размещение объявления с фотографиями и характеристиками;
- связанные справочники марок и моделей;
- импорт объявлений из XML-фида;
- аукционы со ставками, таймером и выбором победителя.

## Локальный запуск

Проект не требует сборки. Запустите любой статический HTTP-сервер в этой папке, например:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Совместная работа

Предложения и ошибки создавайте в GitHub Issues. Изменения разрабатывайте в отдельных ветках и отправляйте через Pull Request.

> Сейчас объявления, ставки и избранное сохраняются в `localStorage`, поэтому данные из разных браузеров не синхронизируются. Для совместных данных потребуется серверная часть.
